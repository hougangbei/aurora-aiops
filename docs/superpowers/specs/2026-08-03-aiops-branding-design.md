# AIOps 平台品牌区设计

**状态：** 已批准，等待实施计划
**日期：** 2026-08-03
**范围：** Web 端左上角品牌区

## 1. 目标

将当前左上角的 `kubejojo` 品牌标识恢复为原始项目使用的 **AIOps 平台**，并使用专属的“A + 节点连接”图标，保持导航结构、折叠行为和响应式布局不变。

## 2. 视觉方案

采用已确认的 **Aurora 节点**方案：

- 图标尺寸保持现有 42px，圆角 12px。
- 背景使用靛蓝到紫色的渐变，形成轻量的品牌识别色。
- 图标中心为白色大写 `A`。
- 右上角加入青色节点，左下角加入淡紫色节点，表达 AI 与运维系统的连接关系。
- 保留轻微阴影和边框，保证在浅色导航栏中清晰可见。

## 3. 文案与布局

- 主品牌文案从 `kubejojo` 改为 `AIOps 平台`。
- 不增加副标题，避免窄侧栏和移动端出现拥挤或截断。
- 继续使用现有 `VersionBadge`，不改变版本信息的位置和行为。
- 图标需要提供准确的无障碍替代文本：`AIOps 平台 logo`。

## 4. 实施边界

- 修改 `web/src/components/brand/BrandLogo.tsx` 的图标呈现，不再依赖现有产品图片。
- 修改 `web/src/layouts/AppLayout.tsx` 的品牌文字。
- 不修改侧栏导航项、颜色主题、页面路由或后端接口。
- 增加/更新前端测试，验证品牌文案和图标可渲染。

## 5. 验收标准

1. 登录后桌面侧栏左上角显示 `AIOps 平台`，不再显示 `kubejojo`。
2. 图标呈现 Aurora 节点方案，42px 尺寸下 `A` 和两个节点清晰可辨。
3. 侧栏折叠、移动端 Drawer 和版本徽章行为保持现状。
4. `npm test` 与 `npm run build` 通过。
5. 浏览器目视验收：浅色侧栏中图标与文字垂直居中，长文案不溢出。
