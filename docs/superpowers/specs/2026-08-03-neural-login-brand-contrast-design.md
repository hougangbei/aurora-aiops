# Aurora AIOps 登录品牌与对比度调整

日期：2026-08-03
状态：设计已确认，待实施

## 目标

让登录首页在第一眼明确体现 Aurora AIOps 平台，同时提升深色背景下登录表单的可见性，不改变认证、演示模式、错误处理、加载状态或导航行为。

## 设计

- 主标题使用两行 `AURORA AIOPS` / `ACCESS CONTROL`，将项目品牌与登录语义放在视觉中心。
- 中文副标题明确说明这是智能运维平台安全访问入口，英文副标题保留控制平面语义。
- Signal Capsule 输入框使用更亮的蓝灰半透明底色、可见边框和浅色占位文字。
- 输入框标签、ID/KEY 标记和密码图标使用更高对比度；聚焦时使用蓝紫色边框与柔和外发光。
- 演示按钮改用深蓝灰底和亮色文字，与主按钮形成层级而不是白底高亮。
- 保留鼠标光效、移动端垂直表单布局、键盘焦点和 `prefers-reduced-motion` 规则。

## 验收标准

1. 页面标题同时包含 `AURORA AIOPS` 与 `ACCESS CONTROL`。
2. 桌面和移动端输入框边界清晰，标签和占位文字可读，不发生横向溢出。
3. 主按钮仍显示 `INITIALIZE SESSION ↗`，演示按钮仍可用且 pending 时禁用。
4. 登录页定向测试、全量测试和生产构建通过。
